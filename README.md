# Safe Q-Web — 모바일 데모 앱

QR / URL 피싱 탐지 및 공유 서비스의 발표용 프로토타입이에요. 백엔드 없이 mock 데이터만으로 동작해요.

## 실행 방법

`index.html` 을 브라우저에서 더블 클릭하면 바로 동작해요. 외부 도구나 설치 단계는 없어요.

> 폰트와 Leaflet 지도 타일은 CDN 에서 가져오므로 처음 한 번은 인터넷 연결이 필요해요.

## 7분 시연 가이드

1. **로그인 화면** — 데모 계정 **`test / 1234`** 로 로그인 (아이디 자동 채움). "네트워크 오류 시뮬" / "잠금 해제" 보조 버튼으로 오류 상태도 보여줄 수 있어요. 자동 로그인은 `localStorage` 에 저장돼요.
2. **홈** — 큰 민트 카드 "QR 스캔하기" 를 탭하면 분석 로딩 → 결과 화면으로 전환돼요. 최근 이력 아이템을 탭해도 결과 화면으로 진입해요.
3. **QR 스캔 결과** — 상단의 **DEMO 세그먼트 컨트롤** 로 `로딩 · 안전 · 주의 · 위험 · 오류` 5 가지 상태를 즉시 전환할 수 있어요. 위험(Danger) 등급에서 "위험 감수" 를 누르면 한 단계 확인 다이얼로그가 떠요. "공유" 는 그룹 선택 시트, "신고" 는 토스트로 마무리돼요.
4. **위험 지도** — 서울 주변 8 개 위험 지점이 표시돼요. 마커 탭 → 상세 시트(신고 건수, 대표 위험 URL). 필터칩으로 등급/기간 토글, 우하단 FAB 로 재중심. 헤더의 핀 아이콘으로 "위치 권한 거부" 상태를 시뮬레이션해요.

## 빠른 진입을 위한 URL 해시

발표 중에 주소창을 활용하면 한 번에 원하는 화면을 띄울 수 있어요.

| 화면 | 해시 |
| --- | --- |
| 홈 | `#/home` |
| 스캔 결과 (안전) | `#/scan?risk=safe` |
| 스캔 결과 (주의) | `#/scan?risk=warning` |
| 스캔 결과 (위험) | `#/scan?risk=danger` |
| 스캔 로딩 | `#/scan?state=loading` |
| 스캔 오류 | `#/scan?state=error` |
| 위험 지도 | `#/map` |

> 해시로 진입하면 데모 계정으로 자동 로그인돼요.

## 파일 구성

```
index.html             # 진입점 — React + Leaflet 로딩
styles.css             # 앱 전용 스타일
colors_and_type.css    # 디자인 토큰 (이영호 / 205 포트폴리오 시스템에서 발췌)
mock-data.js           # 모든 mock 데이터 (사용자, 스캔 결과, 그룹, 위험 지역)
icons.jsx              # Lucide 스타일 SVG 아이콘 + 토스트 호스트
screen-login.jsx       # ① 로그인 / 회원가입·비밀번호 찾기 라우팅
screen-home.jsx        # 홈 — 스캔 CTA + 통계 + 최근 이력
screen-scan.jsx        # ② QR 스캔 결과 (필수) — 5가지 상태 + 위험도 3단계
screen-map.jsx         # ③ 위험 지도 — Leaflet + 마커 + 상세 시트
app.jsx                # 라우터 + 폰 프레임 + 탭바
fonts/                 # OTF 폰트 (Maplestory, OK Mallang 등)
assets/                # 로고 (직접 노출은 안 함, 리소스 보존용)
```

## 디자인 시스템

폰트, 컬러, 간격, 라운드, 그림자 모두 **205 / 엔트리 포트폴리오 디자인 시스템** 에서 가져왔어요. 민트(`--c205-mint`) 가 1차 브랜드 컬러, 핑크(`--c205-pink`) 가 액센트, 무드 그레이(`--c205-bg-mood`) 가 분위기 색이에요. 헤드라인에는 **Maplestory**, 본문에는 **Pretendard Variable**, 위험 점수에는 **OK Mallang** 의 둥근 숫자, URL 에는 **D2Coding** 모노스페이스가 쓰였어요.

## 알려진 한계

- 실제 카메라와 GPS 는 사용하지 않아요. 모두 mock 시뮬레이션이에요.
- 회원가입 / 비밀번호 찾기 / 내 정보 / 알림은 라우팅만 동작하는 자리표시자예요.
- Leaflet 지도는 CartoDB Positron 타일을 써요 — 모바일 네트워크에서 첫 로드만 느려요.
